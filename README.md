# 🚀 BHTTP (DTunnel / Bilola)

Instalador universal y panel de control para protocolo BHTTP en VPS Linux (compatible con **ARM64** y **x86_64**).

---

## 📥 Instalación

Copia y pega este comando en tu terminal:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/wilderusuga514-alt/protocolos/main/install.sh)
```

O clonando el repositorio:

```bash
git clone https://github.com/wilderusuga514-alt/protocolos.git && cd protocolos && sudo bash install.sh
```

---

## 🎛️ Panel de Control

Para gestionar BHTTP (iniciar, detener, cambiar puertos o ver logs), simplemente escribe en tu terminal:

```bash
bhttp
```
